# models/

Place the MediaPipe Face Landmarker model file here before running the app.

**File needed:** `face_landmarker.task`

**Download link:**
https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

Save it as `models/face_landmarker.task`. The file is about 3.6 MB and is not committed to the repository.
