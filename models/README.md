# models/

This folder holds the MediaPipe Face Landmarker model used by the vision module.

**File:** `face_landmarker.task` (about 3.6 MB)

The model file is included in the repository, so it is already here after you clone or pull. You do not need to download it.

If the file is missing or broken, download it again from:
https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

Save it as `models/face_landmarker.task`.
